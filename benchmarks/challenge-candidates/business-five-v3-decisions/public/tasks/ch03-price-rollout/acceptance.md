# 受入項目と観測

共通C01〜C06も必達です。重大違反Cは数値得点と別に記録します。未観測/基盤不良は未達の証拠ではありません。AはHTTPと永続状態/履歴、Bは実ブラウザ、Fは有限障害/競合と外部観測、Rはコードと説明の構造化確認です。実装方式を採点しません。

| ID | 業務結果 | 重要度 | 必要証拠 |
|---|---|---|---|
| M01 | contract.mdの「金額」 | C | A,B,F |
| M02 | contract.mdの「営業互換」 | C | A,B,F |
| M03 | contract.mdの「更新登録」 | C | A,B,F |
| M04 | contract.mdの「商品identity」 | C | A,B,F |
| M05 | contract.mdの「途中再開」 | H | A,B,F |
| M06 | contract.mdの「切替」 | C | A,B,F |
| M07 | contract.mdの「差戻し」 | C | A,B,F |
| M08 | contract.mdの「利用者体験」 | H | A,B,F |

Fは当該項目に定義された停止/競合/外部効果がある場合だけ適用します。存在しない公開操作を要求したり、複数方式を一方式へ限定したりしません。独立評価者が操作・fixtureと適用性を確認し、自己申告だけで対象外にしません。

追加契約business-decisions.mdはM01・M02・M03・M04・M05・M06・M07・M08に帰属します。新規ケース数で配点を増やさず、同じ原因の重複減点をしません。独立な新業務条件がある新版であり、旧答案の旧評価を変更しません。
