# 受入項目と観測

共通C01〜C06も必達です。重大違反Cは数値得点と別に記録します。未観測/基盤不良は未達の証拠ではありません。AはHTTPと永続状態/履歴、Bは実ブラウザ、Fは有限障害/競合と外部観測、Rはコードと説明の構造化確認です。実装方式を採点しません。

| ID | 業務結果 | 重要度 | 必要証拠 |
|---|---|---|---|
| J01 | contract.mdの「要求受付」 | H | A,B,F |
| J02 | contract.mdの「保存物互換」 | H | A,B,F |
| J03 | contract.mdの「担当交代」 | C | A,B,F |
| J04 | contract.mdの「配信と取消」 | C | A,B,F |
| J05 | contract.mdの「不明な配信」 | C | A,B,F |
| J06 | contract.mdの「運用復旧」 | H | A,B,F |
| J07 | contract.mdの「監査」 | H | A,B,F |
| J08 | contract.mdの「利用者体験」 | H | A,B,F |

Fは当該項目に定義された停止/競合/外部効果がある場合だけ適用します。存在しない公開操作を要求したり、複数方式を一方式へ限定したりしません。独立評価者が操作・fixtureと適用性を確認し、自己申告だけで対象外にしません。

追加契約business-decisions.mdはJ01・J03・J04・J05・J06・J07・J08に帰属します。新規ケース数で配点を増やさず、同じ原因の重複減点をしません。独立な新業務条件がある新版であり、旧答案の旧評価を変更しません。
