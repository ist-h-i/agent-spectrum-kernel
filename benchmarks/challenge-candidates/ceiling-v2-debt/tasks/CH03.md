# CH03 v2: 稼働中の価格移行と旧利用側の互換性

価格移行ツールは、単一 writer の夜間移行から、複数 tenant の営業中移行へ拡張されました。旧管理画面は旧形式の応答を使い、新しい画面と移行 worker は別々に動きます。ページ単位の backfill、遅延書込、切替、rollback を同時に使うと値や進捗が食い違います。提供する公開契約を満たすよう既存コードを修正してください。

主な変更範囲は、(1)厳密な金額と旧応答の変換、(2)再開可能な backfill と永続 checkpoint、(3)旧新 writer・queue・切替/rollback の整合性です。内部構成やアルゴリズムは自由です。固定利用側を変更せず動作させてください。

公開 API・エラー schema・割込点・受入条件は `spec/api.md` にあります。Node24.21.0/Linuxarm64、CPU1/512MiB/PID64、外部依存・network なしです。`npm test` を実行し、`src/**`, `test/added/**`, `RESULT.md` のみ提出してください。その他は protected。作業用ファイルは `/tmp` または `test/added/artifacts/**` に置いてください。確認できた動作と未確認項目を RESULT に分けます。書込や queue を捨てる、常時停止する、丸めて移行したふりをする修正は契約を満たしません。
