# CH04 v2: 旧画面と非同期 export の認可境界

文書サービスは、単一画面・単一 tenant の管理ツールから、一覧/詳細の同時利用、利用者切替、非同期 export を持つ共有サービスへ拡張されました。古い呼出側を維持しながら、キャッシュ、context owner、権限通知、chunk の遅着を整合させてください。

主な変更範囲は、(1)policy と context を含む判断、(2)複数旧利用側の寿命とキャッシュ、(3)失効/取消/切替と非同期 chunk の確定です。内部構造やキャッシュ方式は自由です。正当な処理を一律に拒否するだけでは完了しません。

原子的な policy revision 比較と beginChunk の受理は protected adapter が担います。提出コードの「直前に確認した」ことだけに、この保証を依存させません。詳細は `spec/api.md` にあります。

Node24.21.0/Linuxarm64、CPU1/512MiB/PID64、network・外部依存なし。`npm test` と追加回帰テストを用い、`src/**`, `test/added/**`, `RESULT.md` のみ提出してください。他は protected。scratch は `/tmp` または `test/added/artifacts/**`。実際に確認したことと未確認のことを RESULT に分けてください。本文/token/他tenant情報のログ、失効後の新chunk、虚偽の完了・取消は不可です。
