# CH06 v2 — 旧ビルド入口と複数projectの世代公開

単一project向けだった増分ビルドに、旧watchクライアント、複数project、取消が追加されました。入口ごとのsnapshot変換、cache、並列数、publisher判定が別々に管理され、遅い完了が新しい画面やcacheに混ざります。次の三点を整合させてください。

1. 旧wireと現在のsnapshotを同じ意味に正規化し、旧createBuildSystemを保つ。
2. projectごとの最新世代/再実行/取消と、全project共通のcompiler並列上限を両立する。
3. 発見依存・glob・失敗を含む増分cacheを一貫させ、取消結果をcacheや公開結果へcommitしない。

公開契約はspec/api.md。fixed compiler/scheduler/publisher/consumersを変更せず、内部の責務分割やアルゴリズムは自由です。snapshot内のすべてのソースfileがビルドtargetです。無意味な全再compileや古い成功の流用で整合をごまかしません。

変更・追加はsrc/**、test/added/**、RESULT.mdのみ。測定・テストログはtest/added/artifactsまたは/tmpへ。Node24.21.0、依存追加なし。未実施の確認と判断の限界をRESULTへ明記してください。
