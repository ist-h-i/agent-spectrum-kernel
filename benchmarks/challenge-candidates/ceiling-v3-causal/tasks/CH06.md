# CH06 v3 — 選択ビルドと重なる作業要求

共用compilerを使うビルド環境に、旧wireからの呼出し、projectごとの世代、選択target、取消が共存している。sourceには今の要求で不要なものも含まれ、依存関係の一部はcompilerとのやり取りで分かる。変更が続いても、選んだ成果物・再利用・他projectの進行が矛盾しないよう改修する。

仕様の入口は `spec/index.md`。既存callerとproviderを保ち、複数モジュールの責任境界を調査して必要な変更を行う。内部のアルゴリズムや設計パターンは指定しない。

変更可能はsrc/**、test/added/**、RESULT.md。spec/harness/data/package/元testは固定。外部依存/download不要。Node24.21.0 Linuxarm64、非root、CPU1/512MiB/PID64、network/host mountなし。通常testは利用例であり全契約の保証ではない。追加採点test形式はspec/scenario-tests.md。確認済み/未確認をRESULTに分ける。
