# Protected providers

C1 Compiler.inspect(snapshot,path) returns imports and globMatches for that source. A glob has at most one* matching a filename segment, not slash. Compiler.compile({snapshot,path,dependencies}) returns dependencies with its complete required set, ok with output/dependencies, or failed with reason/path. Success requires reconciled dependency artifacts. Direct compiler failures preserve reason/path. Missing dependencies and failed dependencies fail affected importers; cycle reports reason cycle with a closed dependency walk for a cyclic target, while an importer may report dependency_failed. Failure of one selected target does not stop independent ready targets.

C2 Output is deterministic in project namespace, source path/text, compilerVersion, canonical config and sorted dependency path/artifact pairs. Project default retains the old output namespace. Internal metadata attached by implementations is ignored for compilation identity. Direct compiler method results and pending-call handles are protected producer observations, not a storage format for implementations. Public compiler.observation exposes copied calls/pending plus active/peak counters. Manual compiler completes only with complete(id); fair completion is supplied through the finite protected scheduler. No implementation may abort a running compiler call.

C3 Publisher.publish accepts `{projectId,generation,results}` and records a detached copy. latest(projectId='default') and history(projectId?) return copies. The publisher does not decide whether a completion is current; B6 defines the accepted visible history. Fixed source code supplies no atomic transaction spanning builder memory and publisher and no process-crash is injected within one synchronous publication call.

C4 Equivalent dependency negotiations are allowed: a cold source may require an extra provider call when dependencies were not yet known. Provider start order for independent work, opaque IDs, result key order and explanatory prose are not prescribed. Only documented status/reason enums and declared causal effects are scored. Finite scenarios may interleave accepted requests, provider completions and cancellation at public call boundaries.
