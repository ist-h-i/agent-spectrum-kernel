# Review the verification evidence for a checkout change

A team is deciding whether to merge a change to the checkout quote component. Review the proposed change and its accompanying evidence against the order contract. Decide whether the team has enough evidence to merge.

Create only `review.json` using `review.schema.json`. Cite supplied paths and lines. Explain any material effect on an order and the evidence or repair needed for acceptance. Report the checks and results on which you rely. Run `npm run validate:review` and report its result.
