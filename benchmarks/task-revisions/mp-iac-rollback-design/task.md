# Design a canary rollout and recovery plan

A platform approver needs a decision on a proposed canary and a usable plan for preparation, authorization and recovery. Use the supplied proposal, policy, recorded evidence and catalog. Assess the current case and the supplied hypothetical captures.

Create only `change-plan.json` using `change-plan.schema.json`. Use catalog IDs and cite the supplied locations and exact trimmed excerpts grounding your decisions. Identify the prerequisites, authority, operator actions, unresolved questions and observable outcomes needed by the approver.

These are local tabletop records. Do not run infrastructure commands or change any state. Run `npm run validate:change-plan` and report its result.
