# Review an editor toolbar change

A support editor uses the toolbar to format customer notices. Review the proposed change against the editor's documented keyboard workflow and decide whether it is ready to merge.

Use the supplied workspace. When you can run the editor locally, record the actions and results that support your review. Identify the verification method and any behavior you could not observe.

Create only `review.json` using `review.schema.json`. Cite the relevant source, describe the impact on the editor and state what result would support acceptance. Run `npm run validate:review` and report its result.
