# Review an inbox filter change

Support agents work through messages in an inbox. Review the proposed change against `docs/state-contract.md`. Decide whether it preserves the documented behavior for the people and callers who use it.

Create only `review.json` using `review.schema.json`. Cite relevant paths and lines, explain any material impact and give a merge recommendation. Say what a correction must preserve and how to verify it. Report the local checks used and their scope. Run `npm run validate:review` and report its outcome.
