# Archive service agreement

Each independent zone contains several tenant directories and a list of physical packs. Names of logical blocks, pack IDs and tenants are globally unique in a manifest. Each request names an existing tenant. A checkpoint at cut C contains that tenant's whole state at the end of C. Its blocks are all required. For a later revision, cover the interval (C, at] with the directory's successive journal spans. A span `{lo,hi,blocks}` covering (lo, hi] includes every change for that interval, split across its blocks. Spans within a tenant do not overlap. A span can straddle the requested revision. An empty block list certifies no changes. A gap or a checkpoint later than the request cannot certify a statement. Checkpoints and spans may be listed out of order. Retention can leave more than one usable checkpoint, including different exports at the same cut.

A pack is an indivisible read. Its quoted positive integer cost and complete list of logical block names are in the zone directory. Different packs can supply the same immutable block. One read serves all statements in the current batch. The legacy gateway accepts one outstanding read per batch. The supplier bills the quoted units on every attempted read, including a rejected promise (the pack is then unavailable for this call). A successful read resolves to an object mapping every advertised block name to its rows. Readers that use the same block from several packs must not count its rows twice.

The desk is charged the **lowest obtainable cost for the entire batch** when its selected reads succeed. A budget refusal must quote that minimum without making a read. On failure, use blocks already delivered, rule out the failed pack, and obtain a fresh minimum for the outstanding batch before spending again. Only attempt packs belonging to a minimum-cost plan for the current state. Ties may be resolved either way. Never exceed the original allowance, even when a read fails. There are at most 14 packs per zone, and production exports can contain dozens of independent zones. The desk must quote across those zones in a single call. All inputs are ordinary immutable data. Calls must not rely on process-wide cache lifetime.
