# Archive service agreement

Each zone lists several tenant directories and a list of physical packs. Names of logical blocks, pack IDs and tenants are globally unique in a manifest. Each request names an existing tenant. A checkpoint at cut C contains that tenant's whole state at the end of C. Its blocks are all required. For a later revision, cover the interval (C, at] with the directory's successive journal spans. A span `{lo,hi,blocks}` covering (lo, hi] includes every change for that interval, split across its blocks. Spans within a tenant do not overlap. A span can straddle the requested revision. An empty block list certifies no changes. A gap or a checkpoint later than the request cannot certify a statement. Checkpoints and spans may be listed out of order. Retention can leave more than one usable checkpoint, including different exports at the same cut.

A pack is an indivisible read. Its quoted positive integer cost and complete list of logical block names are in the zone directory. Different packs can supply the same immutable block. One read serves all statements in the current batch. The legacy gateway accepts one outstanding read per batch. The supplier bills the quoted units on every attempted read, including a rejected promise (the pack is then unavailable for this call). A successful read resolves to an object mapping every advertised block name to its rows. Readers that use the same block from several packs must not count its rows twice.

The desk is charged the **lowest obtainable cost for the entire batch** when its selected reads succeed. A budget refusal must quote that minimum without making a read. On failure, use blocks already delivered, rule out the failed pack, and obtain a fresh minimum for the outstanding batch before spending again. Only attempt packs belonging to a minimum-cost plan for the current state. Ties may be resolved either way. Never exceed the original allowance, even when a read fails. Typical regional exports have dozens of tenants. The national directory can contain hundreds of packs, split across depot routes and branches. The desk quotes the national directory in one call. All inputs are ordinary immutable data. Calls must not rely on process-wide cache lifetime.

## National archive schedule

A zone identifies the publishing office. A pack can contain logical blocks belonging to other offices. A manifest can declare `openings`, an object mapping depot route IDs to nonnegative setup units, and assign any pack a `route` from that table. The first attempted pack on a route in this call incurs that route’s setup units in addition to its pack cost, even if the read fails. Later attempts on that route incur only their own pack cost. Packs without a route have no setup charge. The desk quotes the minimum including all additional setup charges. Setup expires at the end of the call.

The archive retains statements as issued, including publications affected by later journal corrections. A request may include the nonnegative integer `edition` on the printed statement (default 0). A checkpoint or journal span can carry a `valid` pair `[firstEdition, endEdition]`. The first edition is included, the end excluded; a null end is open. A missing pair covers every edition. At a given edition the eligible journal spans do not overlap. The archive certifies a history only through checkpoint and spans valid together at the requested edition. Physical blocks remain immutable across all publications.
