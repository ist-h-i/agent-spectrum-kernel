# Batched local event lookup

lookupEvents(events, requests) returns one group per request, in request order, including duplicate request identifiers. Each group contains request_id and an events array. Select records by strict identity equality of tenant and kind and an inclusive timestamp window. Only finite numeric event timestamps and finite start/end values are eligible. Inverted or absent windows return an empty group. Null/non-object event records are ignored. Data records and requests have ordinary data properties; side-effecting accessors, proxies, external resources and concurrent input mutation are outside this local contract.

Preserve matching event object identities and their original occurrence order, including duplicate occurrences. Do not mutate input arrays/records, sort inputs in place, or retain cross-call results. Repeated calls must observe changes to input contents and boundaries. Row fields and selector fields may be numbers, strings, booleans, null, undefined or object references. Equality means ===, not string coercion or serialization. A compound key must not collapse distinct components. An unchanged identity with changed data between calls is still a new lookup.
