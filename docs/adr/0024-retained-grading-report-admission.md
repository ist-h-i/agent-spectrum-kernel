# ADR-0024: Admit a distinct retained grading report through a model-free port

- Status: Proposed
- Date: 2026-11-08
- Extends: ADR-0023
- Supersedes: None

## Context

The unused-verifier boundary cannot repair a grading procedure after both roles
are consumed or revisit a valid reference judgment. A new grading protocol must
not be disguised as an unused slot, replay a Task, discard a low result or lose
failed grading cost. Saved execution and source remain useful even when quality
or billing is incomplete.

## Decision

Keep expensive grading outside this import port. A separately configured,
pinned host inspector receives an explicit evidence manifest and paired scope
of latest retained attempts. It runs with model and Task grants zero. Bind the
original native requests/results, approved plan, report, operation, profile,
configuration and cycle policy. Lock the evaluation and both coordinators.
Verify the context again after inspection. A consumed uncertain inspection is
inspected rather than dispatched again.

The inspector owns case-specific grading semantics, fixed calculator evidence,
source and judgment correspondence, finite nonsemantic serialization repairs,
role closure and upstream usage. The kernel verifies exact references, native
transport, artifacts, typed source summaries, scope and limits. No private test
catalog or scoring model is bundled. Caller source points remain separate from
formal/native/runtime qualification.

Fresh host-AI use/reference/exclude decisions select evidence for comparison.
Preserve original results, quality, dispositions, Task measurements and low
scores. Snapshot every consumed old supplement and new inspection, including
unselected/failed/unknown work, separately from adoption of a judgment. Upstream
role records repeated by multiple evidence inspections are observations of the
same work, not additive charges. Complete cost and uncollected host usage stay
unknown.

Publish an immutable typed report. The existing supervised revision transition
creates a new human result/change packet, replans when necessary, rejects old
approval and supplies bounded source points to the next cycle. After its exact
journal admission, review/resume/feedback use stored data without executing old
inspectors or requiring expired caller code. This grants neither grading replay
nor permission to apply assets.

## Consequences

This adds an opt-in report kind and peer store; it does not weaken ADR-0023's
unused-role eligibility. Hosts still need an independently verified inspector
for their own grading format. A source summary, model-free inspection or local
CLI exit cannot certify evidence truth or runtime acceptance. Original and
revised reports remain inspectable and human application approval stays distinct.
