## 暫定の提供範囲

この表は機能の所在と受入境界を示します。最終提供範囲の採用判断はA5.4/A5.5の結果で確定します。

| 範囲案 | 存在する実装・保存証拠 | まだ一般化できないこと |
| --- | --- | --- |
| ローカル導入・診断・復旧 | [Mac / Codex導入](quickstart-mac-codex-ja.md)のsetup、doctor、人工repoでの導入・更新・復旧検証 | 実Macの全運用、全profile・全OS、異なる版間の互換性 |
| Prompt候補の生成・確認 | [個人CLI](personal-evolution-cli.md)と[一度の開始で進めるrun](personal-evolution-unattended.md)。保存runでは候補5ファイルとsource reviewの承認を確認 | 任意のSkillの自律改善、未知のproviderや実効contextの保証 |
| 固定した比較・採点・判断保存 | 保存runではbaseline/challengerのP/K2/F計6条件と元採点、判断、receiptを保存 | 全24課題のnative受入、採点不能の解消、一般的な品質向上やSkillの優位性 |
| 結果の再読込・次回への参照 | 元C1の再読込と、そのreceiptを引き継ぐ独立先の次requestを確認。旧source・採点版のまま`prepared / NOT_RUN` | 実次サイクルの終端、版をまたぐ連続実行、反復実運用の完了 |
| 保留・棄却・適用の分離 | 証拠不足のno-op、候補棄却の契約と人工試験、適用に別権限を求める境界 | Portfolio採用や実Mac設定への自動適用・復元。保存runでは行っていない |

個人CLIの対象はPromptです。現行CLIは候補のPortfolio採用や実targetへの設置を実行しません。既存v1目標の採用時の実target適用を満たすには、適用先・書込範囲・権限・検証・復旧を定めた別の実装契約と受入が必要です。チーム向け共有、任意Skillの自動改善、無条件の採用・適用、完全な操作監視は今回の提供範囲に含めません。A4の課題整備や既存の正式研究は別の完了条件を保持します。
