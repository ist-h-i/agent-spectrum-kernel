## Commands and persistence

Use a new absolute root below a canonical existing parent outside the checkout:

```sh
node scripts/ask-local-full-package.mjs prepare-complete /canonical/work-area/new-full
node scripts/ask-local-three-arm.mjs prepare /canonical/work-area/new-comparison
node scripts/ask-local-three-arm.mjs simulate /canonical/work-area/new-comparison sha256:RETURNED_PROTOCOL_DIGEST
node scripts/ask-local-three-arm.mjs replay /canonical/work-area/new-comparison sha256:RETURNED_PROTOCOL_DIGEST sha256:RETURNED_RESULT_DIGEST
```

Keep both returned digests outside the mutable record directory. Preparation
refuses existing roots. The comparison root has `preparation` and `control`
siblings, with owner-only 0700 directories and 0600 records. `control` is outside
all three task roots. The one-time model-free claim survives failure; a second
simulation is refused. Failed/unknown transport, missing usage, identity mismatch,
reused session, timeout and token threshold stop before the next slot. Missing,
changed, extra or linked evidence blocks replay; replay starts no model, installer
or transport. Directory ACL and live process-read isolation remain unknown.

The synthetic driver uses explicit post-trial thresholds: 120 seconds, 50,000
input-plus-output tokens including cached tokens per slot, 150,000 per block,
zero retries. Reaching a threshold stops subsequent slots. These fields define
the model-free protocol and an unadmitted future budget proposal; they do not
issue a grant or authorize any spending. Existing two-arm budgets are unchanged.
Elapsed times, token counts, sessions and identity observations in this driver
are synthetic and labelled as such. No task output or private semantic score is
fabricated. `synthetic_protocol_complete` means protocol-only completion;
`measured_comparison_valid=false`, semantic scores unknown and contrasts unavailable.

The actual model-free observation at this source is: public input and verification
command binding verified; existing public evaluator source identity refused for

human admission review and Kernel fairness still require qualification. Runtime
