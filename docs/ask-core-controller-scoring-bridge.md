The connection accepts a bounded journal, an independent review archive and a separately retained owner attestation. Its explicit assurance is `repository_owner_attested_controller_archive`, with no cryptographic provider signature. The owner must establish the journal's actual producer and reviewer invocation associations using the controller's original records; distinct caller-supplied IDs, task names, echoed UUIDs and self hashes are insufficient. The attestation accepts attribution for scoring only. It never authorizes model execution, private reads, authentication changes or a new trial. No key, credential or persistent trust configuration is installed.

The journal freezes the exact implementation HEAD, complete profile source pins, product, request, original evaluator bundle/freeze, grader input inventory, every public calculation input/result digest and normalized condition/run/case/attempt/terminal lineage. The archive binds that journal and distinct producer/reviewer contexts and records independent approval. Opaque in-process context objects prevent serialized evidence from becoming an active context. Changing a synthetic label does not satisfy native capture verification. Owner/controller/host honesty remains a trust assumption: this is not signed service identity or proof against a compromised controller. Native attribution additionally replays an actual saved connected normalization, checks its native evidence class, captured HEAD/source/request/product/task and the arm's capture/terminal inventory, then compares every original candidate file's bytes/digest with the captured task workspace. Public capture/source verification precedes declared private scoring input reads. The caller needs separate explicit private-read/grader permission. It does not promote the old always-blocked provenance record.

The bounded scorer connection uses the additive plain/core/full profiles for the complete original verifier and unchanged raw scorer. It verifies private bundle, original source/freeze, original run/materialization/selection/command/candidate authority and private evaluation record through the existing verifier. It then calls the original pure calculation once, preserving explicit failure/unknown outcomes. It does not rename conditions or alter original schemas, evaluator, criteria, freeze, product or historical evidence. The original hidden evaluator's actual acceptance of Core/Full is still Unknown; incompatibility stops before comparison rather than modifying that sealed evaluator.

Native scoring verifies the current controller checkout's actual HEAD using a bounded read-only Git call before and after the original verifier. The original sealed source root and current additive schema/profile source root are distinct: sealed code is verified at its original revision, while schema extension selection remains pinned to this connection's source. No schema profile survives a synchronous call or propagates to asynchronous descendants. The connection consumes original normalized/run/private evaluation artifacts; generating those from an actual native capture is still a separate required adapter step, not a fabricated journal entry.

The original sealed verification may execute its private worker twice for determinism. This connection invokes the verifier once, then computes and persists without a second verifier invocation. Any earlier private-evaluator-runner invocation is separate and must also be counted in the final authorized process budget. Offline replay requires the externally retained capsule SHA and three independently retained attribution SHAs (journal, review archive, owner attestation), reads the saved capsule and public sources only and invokes neither verifier nor grader/model/CLI. Its result is always `offline_calculation_only` / `not_reauthenticated`; it does not accept a new owner attestation or verify native origin. Coherent replacement of synthetic owner/journal labels with native labels is rejected against the original attribution pins. Private authority is not recreated by offline replay.
